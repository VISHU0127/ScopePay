# ScopePay demo — approximately 2 minutes 45 seconds

**0:00–0:20 — Problem and mode.** “ScopePay helps freelancers review additional work before agreeing a price. Today I am using [private simulated demo / configured PayPal sandbox]. One sandbox merchant receives all payments; this is not a marketplace.” Start a private demo from Sign In, or sign in with your prepared Supabase account for genuine sandbox checkout.

**0:20–0:50 — Agreement.** Create a project, load/paste the sample agreement, and extract scope. Show the source beside the editable items and missing details. “These are suggestions until I review and confirm.” Confirm scope.

**0:50–1:15 — New request.** Submit “Please add appointment booking with calendar sync.” Show the suggested classification and supporting quotation. “Matching text is evidence for my review, not proof that an AI interpretation is legally correct.” Edit the client reply if needed.

**1:15–1:45 — Proposal.** Draft the proposal, review acceptance criteria, and enter $1.00 USD yourself. Preview it. Generate/open the client link. “Approval applies to an exact version; changed terms need a new version and new approval.”

**1:45–2:25 — Approval and checkout.** Enter the buyer's name/email and approve. Explain that the shared link is not verified identity. For genuine sandbox, continue to official PayPal, use the prepared sandbox personal buyer, approve normally, return and select Verify payment status. For the private demo, select Simulate demo payment and say explicitly that no PayPal request occurs. Never present simulation as a live exchange. If buyer login takes longer, show the state honestly rather than inventing a result.

**2:25–2:45 — Result.** Show the server-confirmed status, project activity and dashboard totals. “Proposed, approved-unpaid and completed amounts are separate. Pending or uncertain payment is never shown as completed.” Mention any unexecuted sandbox checks.

Preparation: keep the buyer already signed in for a genuine sandbox demo, configure webhooks and persistent storage ahead of time, and retain the original client link. Private demo links work in that browser session only.
